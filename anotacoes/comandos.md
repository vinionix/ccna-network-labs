# Comandos úteis

## Packet Tracer — PCs

Abrir terminal do PC:

```text
Desktop -> Command Prompt
```

Testar conectividade:

```text
ping <ip-de-destino>
```

Exemplo:

```text
ping 192.168.1.20
```
