# Glossário

## Switch

Equipamento que conecta dispositivos dentro da mesma rede local. Trabalha principalmente com endereços MAC.

## Roteador

Equipamento que conecta redes diferentes e decide para onde os pacotes devem ir.

## Gateway

Endereço usado por um host para sair da própria rede. Normalmente é o IP do roteador.

## Modem / ONT / ONU

Equipamento que conecta a rede local à tecnologia da operadora. Em fibra óptica, normalmente é chamado de ONU ou ONT.

## DHCP

Serviço que entrega automaticamente IP, máscara, gateway e DNS para os dispositivos.

## DNS

Serviço que traduz nomes para IPs.

Exemplo:

```text
google.com -> endereço IP
```

## NAT

Tradução de endereços. Permite que vários dispositivos com IP privado saiam para a internet usando um IP público.

## STP

Spanning Tree Protocol. Protocolo usado em switches para evitar loops de camada 2.

## LAN

Local Area Network. Rede local.

## VLAN

Rede local virtual. Permite separar logicamente redes dentro de switches.

## Subnetting

Técnica de dividir redes em sub-redes menores.
